# V3-sb

盘后信号来自沪深主板涨停池。排除 ST、退市整理股，并要求已观测上市日龄至少 60 日、20 日均成交额至少 3000 万元。

- 首板池按涨停池连板数识别首板。
- V3 池取非一字涨停且有足够 20/60 日动量历史的股票。V3 分数作为诊断字段，开盘排序用整个合格 V3 候选池。
- 按买入日开盘缺口由低到高排序，首板先选一只，V3 剔除已选股票后再选一只。同缺口按信号日成交额由高到低。
- 每笔最多 1 万元、100 股整手，计划下一交易日收盘退出。开盘缺口低于或等于 −9.9% 的信号跳过。
- 每个交易日收盘后生成当天开盘模拟信号，存入 reports/。支持 Actions 手工填写买入日重放，日期范围受涨停池接口限制。

日线开盘价是模拟成交代理。日线逐票校验日期与字段，东方财富失败或返回过期数据后切换新浪；前复权收盘价另有腾讯备用。只复用包含目标日期的缓存。缺失股票单独重试，仍失败则保存部分预选和逐票错误清单，不生成最终模拟买入排名。涨停池整体不可用仍明确报错。报告包含入场模拟与计划卖出时间，无券商连接。

任务北京时间16:12运行，17:42和19:22补跑；GitHub调度可能延迟。未指定日期时使用最近已收盘交易日，凌晨延迟运行不会索取尚未形成的当天日线。预选与模拟独立执行，任一阶段失败仍保存另一阶段产物。覆盖状态见 reports/quality/ 下的 JSON，partial不代表完整扫描。

盘后预选写入 `reports/preselect/YYYY-MM-DD.md`，日期为信号日。手工生成指定信号日预选可运行 `python scan.py --preselect --buy-date YYYY-MM-DD`。
